## Experiences

Discover the best ways to use pack offers with Experiences. Experiences are curated bundles of pack partner products, GitHub tools, and other resources that are designed for you learn new skills and make the most out of the Student Developer Pack and your journey in GitHub Education.

### LaunchPad: Intro to Copilot
* **Description:** What is Copilot and how do you get started using it? Use this Experience as a Primer on Copilot. We share tutorials, guides and templates to learn how to use AI in your development process.
* **Offers in this bundle:** GitHub, GitHub Copilot, GitHub Codespaces, Visual Studio Code
* [Learn more about Intro to Copilot](https://education.github.com/experiences/intro_to_copilot)

### LaunchPad: Intro to GitHub
* **Description:** GitHub flow is a lightweight, branch-based workflow. In this Experience you'll learn the basics of the GitHub Flow including creating and making changes to branches within a repository, as well as creating and merging pull requests. The GitHub flow is useful for everyone, not just developers.
* **Offers in this bundle:** GitHub
* [Learn more about Intro to GitHub](https://education.github.com/experiences/intro_to_github)

### Tools: GitHub Foundations Certification
* **Description:** Everything you need to get started preparing for and taking the GitHub Foundations Certification exam including FAQs, guides, prep courses, and more.
* **Offers in this bundle:** DataCamp, GitHub, Microsoft Azure
* [Learn more about GitHub Foundations Certification](https://education.github.com/experiences/foundations_certificate)

### Tools: Intro to Open Source
* **Description:** Everything you need to know to understand the origins of open source work, how to become a contributor, a maintainer or a sponsor of an open source project and how to propel open source work into a career. Start with the basics including intro guides, how to find good first issues and basic open source vocabulary. Then begin to explore some of the best tools and thought leadership that will help you discover new ways of contributing.
* **Offers in this bundle:** Travis CI, GitHub, OpenSauced, GitHub Codespaces, +4
* [Learn more about Intro to Open Source](https://education.github.com/experiences/intro_to_open_source)

### Tools: AI Prompting & Technical Writing
* **Description:** This Experience offers the tools, top tips and resources you'll need to get started becoming a technical wizard with words.
* **Offers in this bundle:** GitHub, Microsoft Azure, Educative, POEditor, +2
* [Learn more about AI Prompting & Technical Writing](https://education.github.com/experiences/ai_prompt_tech_writing)

### Tools: Intro to Web Dev
* **Description:** Everything you need to build your next website. Learn how to design and build your own website as you learn the basics of web development.
* **Offers in this bundle:** LambdaTest, Polypane, Bootstrap Studio, Microsoft Azure, +3
* [Learn more about Intro to Web Dev](https://education.github.com/experiences/intro_to_web_dev)

### Tools: Data Science & Machine Learning
* **Description:** Flex your skills in data collection, cleaning, analysis, visualization, programming, and machine learning. The Data Science & Machine Learning experience gives you the tools to analyze, collaborate and harness the power of predictive data to build amazing projects.
* **Offers in this bundle:** Datadog, SQLGate, GitHub Codespaces, Deepnote, +2
* [Learn more about Data Science & Machine Learning](https://education.github.com/experiences/ml_ds)

### Tools: Mobile App Development
* **Description:** Have an idea for a mobile app you'd like to bring to life? This Mobile App Development Experience gives you the tools, resources and inspiration to design, build, test and deploy your next mobile application.
* **Offers in this bundle:** Microsoft Azure, FrontendMasters, LambdaTest, NativeScript, +2
* [Learn more about Mobile App Development](https://education.github.com/experiences/mobile_app_development)

### Tools: Virtual Event Kit
* **Description:** Everything you need for your virtual event. Design for engagement and we'll take care of the tools. The Virtual Event Kit gives students the resources to make running online events simple and accessible.
* **Offers in this bundle:** Namecheap, Microsoft Azure, Name.com
* [Learn more about Virtual Event Kit](https://education.github.com/experiences/virtual_event_kit)

### LaunchPad: Profile README
* **Description:** Say ‘Hello world’ with a profile README that lets you introduce yourself to the GitHub community. You decide what information to include in your profile README, so you have full control over how you present yourself on GitHub. This experience walks you through a quick tutorial to create your profile README.
* **Offers in this bundle:** GitHub
* [Learn more about Profile README](https://education.github.com/experiences/launchpad_profile_readme)

* **Offers in this bundle:** Scrimba
* [Learn more about Launchpad: Intro to Javascript](https://education.github.com/experiences/launchpad_javascript)
